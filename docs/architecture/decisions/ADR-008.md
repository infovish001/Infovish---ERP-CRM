# ADR-008 Official WhatsApp Business APIs

Date: 2026-10-30

Status: Proposed for future milestone; boundary accepted for M01. No independent owner sign-off is claimed.

## Context and decision

Use Cloud API or authorized provider in M09 after policy review.

## Alternatives and rationale

Considered: Unofficial browser/session automation. Official callbacks and account lifecycle support auditable delivery.

## Consequences and risks

Consent, signature checks, templates and deduplication are mandatory.

## Security and operations

Apply least privilege, tenant context validation, safe errors and redacted logs. Never use this decision to bypass authorization. Operational validation must be evidenced in the milestone that implements the capability.

## Migration and review

M01 is a new foundation, so no existing production data migration is needed. Later changes use a superseding ADR, compatibility-aware expand/contract schema changes and measured rollback/restore plans. Reassess before implementing the affected subsystem; unapproved future scope remains deferred.

Related requirements: COM-001 through COM-013; BR-COM. Source: SAD section 14 and the master request.
