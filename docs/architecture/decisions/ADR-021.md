# ADR-021 CRM ownership and atomic conversion

2026-10-30. Selected for the authorized M04 baseline by architecture lead.

CRM owns leads, pipelines/stages, opportunities, activities and immutable transition history. It depends on the Parties public Contacts contract for customer lookup/creation, never its private tables. Conversion is one tenant transaction under existing lifecycle/idempotency locks with a unique lead/opportunity link; it records explicit conversion intent and returns the same result for matching retries. Reuse of an existing customer is an explicit user choice.

Extend shared mutation authorization with an allowlisted CRM permission while retaining the default privileged organization permission for existing modules. Members manage assigned CRM records within company grants; auditors read scoped records; privileged MFA users reassign, convert, configure pipelines and reopen. Assignment and lifecycle checks are repeated inside transactions. The event journal revalidates a CRM member author's active company membership but performs no later CRM action on their behalf.

Store forecast amounts as NUMERIC(20,6) and explicit probabilities as integers. Use exact PostgreSQL numeric multiplication/division and round each nonnegative weighted estimate half-up to six places, then sum. Never treat estimates as recognized revenue or mix currencies. Changing stage probabilities affects current estimates; historical snapshots are deferred.

Alternatives rejected: CRM writes to Parties tables violate ownership; silent merge can corrupt customer identity; client-only permissions leak assignments; floating point or arbitrary fixed probabilities misstate estimates. M04's additive schema 3 preserves older master data; migration execution remains operator-only. Monitor tenant-wide mutation lock contention before production scale.

Sources: PRD CRM/BR-CRM/AC-CRM and SAD sections 3-6/9; [PostgreSQL numeric types](https://www.postgresql.org/docs/17/datatype-numeric.html) and [Laravel validation](https://laravel.com/docs/13.x/validation), inspected 2026-10-30. See M04_SPEC and M04_REPORT for exact scope/evidence.
