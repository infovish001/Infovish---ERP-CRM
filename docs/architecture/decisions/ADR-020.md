# ADR-020 bundled module lifecycle and shared transactions

2026-10-30. Selected for authorized M03 by architecture lead; no independent approval claimed.

Resolve only explicit bundled manifests, with framework-major compatibility, acyclic dependencies and immutable public DTO contracts. Platform metadata grants entitlements; tenant metadata controls activation. Require schema readiness, entitlement, activation and current company/actor authorization at application boundaries. Browser activation never executes DDL. Migrations run through a separately credentialed operator and preserve data on deactivation/failure.

Parties and Catalog own their tables/migrations/contracts. Shared infrastructure owns counters, idempotency and ID-only outbox/receipt records, with all state committed in the same tenant transaction. Use PostgreSQL transaction locks for counters/idempotency and row locks plus revisions for edits. List prices are decimal strings with six places, no arithmetic/rounding policy or accounting behavior.

Publish Redis jobs at least once; deduplicate the internal event journal transactionally. Reauthorize jobs and keep errors redacted; bounded retries move to inspectable dead-letter state with audited administrator replay. This extends ADR-006 without claiming future business subscribers. Queue publication failure leaves the durable outbox retryable; successful enqueue followed by a crash can duplicate delivery. Production needs monitored dispatch scheduling and retention/recovery policy.

Alternatives: dynamic plugin loading increases arbitrary-code risk; synchronous publish can lose committed events; floating point amounts lose precision; automatic DDL on activation couples web privileges to provisioning. The selected design costs platform entitlement lookups and tenant locks, to be measured before production scale.

Sources: PRD MOD/DEP/NFR ranges and SAD sections 3–6/9; official [Laravel queues](https://laravel.com/docs/13.x/queues) and [migrations](https://laravel.com/docs/13.x/migrations), inspected 2026-10-30. See M03_SPEC for scope and M03_REPORT for actual evidence.
